# Project Overview

Organizations increasingly rely on data to understand employee performance, engagement, and workforce well-being.

This project consists of designing an interactive Human Resources Analytics Dashboard that enables HR managers and executives to monitor key workforce indicators, identify trends, and support strategic decision-making.

The dashboard combines data modeling, ETL, DAX calculations, and interactive visualizations to transform HR data into meaningful business insights.

---

# Business Challenge

Human Resources departments often manage large amounts of employee information spread across different systems.

Without centralized reporting, organizations face several challenges:

- Limited visibility into workforce performance
- Difficulty monitoring employee engagement
- High employee turnover
- Lack of actionable HR KPIs
- Time-consuming manual reporting
- Difficulty identifying workforce trends

The objective of this project was to build a centralized HR Analytics solution capable of providing reliable insights for decision-makers.

# My Approach

Collected HR datasets containing information about:

- Departments
- Performance

- Attendance
- Salaries
- Demographics

## Data Cleaning

Performed data preparation using Power Query:

- Remove duplicates
- Handle missing values
- Standardize formats
- Validate data consistency
- Normalize datasets

---

## Data Modeling

Designed a relational data model using best practices.

The model included relationships between:

- Employees
- Departments
- Positions
- Performance Reviews
- Training Records
- Attendance
- Workforce Metrics

A star schema was implemented to optimize Power BI performance.
